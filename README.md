# KIO DB

В данном репозитории будет лежать колоночный движок. На данный момент из 
возможностей есть только конвертация .csv файлов в .kiodb формат для хранения 
колоночной базы данных и обратно. Вот краткое описание каждой секции:

### CSV WORK

В данной директории лежат все файлы, позволяющие конвертировать .csv файл в 
структуру, в которой будут производиться все вычисления и обратно.

csv-row_parser - парсинг строк csv файла
csv-batch_reader - чтение csv файла батчами с последующим парсингом
с помощью csv_row_parser
csv-formatter - форматирование распаршенного батча с построчным типом 
хранения данных в колоночный
csv-exporter - форматирование батча с колоночным типом хранения данных в 
построчный, а также создание csv файла с этими данными

### KIO Work

в данной секции лежат файлы, которые читают и пишут kiodb файлы, а также отвечают
на запросы (на данный момент есть только чтение и запись)

kio_db - основной модуль для вычислений
kio_db_reader - чтение kiodb файла в оперативную память
kiodb_writer - запись колоночного формата хранения данных в файл


### General files (src)

В данной секции лежат файлы общего назначения

columnar_types - сборник алиасов и структур, которые используются во всем проекте
schema - структура, которая содержит всю информацию о типах и столбцах таблицы. Также данный
класс используется для уникфикации работы с каждым форматом файла. Для того, чтобы формат
поддерживался колоночным движком, он должен наследоваться от schema. Позже в schema появятся
вирутальные методы, которые позволят работать с любым файлом любого формата одинаково
