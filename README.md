# Обзор папок

## global 

Здесь лежат файлы с типами, функцями и схемами, которые нужны в каждой части проекта

## transport

в данной директории лежат файлы, отвечающие за сжатие, хранение и передачу данных

# kio

файлы, для чтения и записи колоночноо формата в/из оперативной памяти и из .csv формата

# csv

файлы, для чтения и записи .csv в/из оперативной памяти и из колоночного формата

# compression

файлы с поддержкой разных видов сжатия

## execution

Здесь лежат файлы, отвечающие за выполнения запросов (операторы, проще говоря)
